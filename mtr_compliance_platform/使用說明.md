# 使用說明（給不寫程式的你）

這份工具啟動一次之後，之後每天用就是打開瀏覽器點一點，不用打任何指令。以下是第一次設定的步驟。

## 第一次設定（大約10-15分鐘，只需做一次）

### 步驟 1：安裝 Python
1. 前往 https://www.python.org/downloads/ ，下載並執行安裝程式
2. **Windows使用者注意**：安裝畫面最下方有個 "Add python.exe to PATH" 的勾選框，**務必打勾**，再按安裝
3. Mac使用者通常已內建 Python，可跳過本步驟（若下面步驟出現「找不到 Python」再回來安裝）

### 步驟 2：安裝 Tesseract（讓工具能辨識「掃描/照片」證書用的，若你只會用電腦原生PDF可跳過）
- **Windows**：前往 https://github.com/UB-Mannheim/tesseract/wiki ，下載安裝程式並執行（一路下一步即可）
- **Mac**：打開「終端機」App，貼上 `brew install tesseract tesseract-lang` 後按 Enter（若沒裝過 Homebrew，先參考 https://brew.sh）

### 步驟 3：下載程式碼
1. 打開這個網址：https://github.com/ANTONIOLIU20250416/__test__/pull/1
2. 頁面上方會看到分支名稱 `claude/mtr-material-analysis-tool-jemlbv`，點它旁邊的連結進到該分支的頁面
   （或直接開：https://github.com/ANTONIOLIU20250416/__test__/tree/claude/mtr-material-analysis-tool-jemlbv ）
3. 點右上角綠色的「**Code**」按鈕 → 點「**Download ZIP**」
4. 下載完後，把 ZIP 檔解壓縮到你電腦上一個好找的地方（例如桌面）
5. 打開解壓縮後的資料夾，進入 `mtr_compliance_platform` 這個子資料夾

### 步驟 4：啟動工具
- **Windows**：雙擊 `START_HERE.bat`
- **Mac**：雙擊 `START_HERE.command`（若跳出「無法打開，因為來自未識別的開發者」，在 Finder 裡對檔案按右鍵 → 打開，再按一次「打開」確認即可）

第一次啟動會多花幾分鐘自動安裝需要的套件，過程中黑色視窗會跑一堆文字，是正常的。跑完之後瀏覽器會自動打開工具首頁。

## 之後每次使用

直接雙擊同一個檔案（`START_HERE.bat` 或 `START_HERE.command`）就會啟動並自動開網頁，不會再重新安裝，幾秒鐘就好。

要關閉工具時，把跳出來的那個黑色視窗關掉即可。

## 日常怎麼用

1. 打開的網頁點「**Upload MTR**」
2. 選供應商 → 上傳證書檔案（PDF、掃描檔、手機拍照都可以）→ 按「Analyze Certificate」
3. 幾秒後會顯示 PASS / WARNING / FAIL，逐項化學成分/機械性質都列出來
4. 「**Dashboard**」看整體風險總覽；「**Env. Certificates**」管理 RoHS/REACH 等證書到期提醒
5. 「**Spec Library**」可以自己新增公司實際會用到的牌號規格（例如 C87850、你們的鐵件牌號等），
   填化學成分範圍（Cu/Zn/Pb/Sn...）跟機械性質下限，存起來之後上傳證書就會自動比對這個規格

整個流程**預設完全在你自己電腦上運算，不會連到 AI 服務、不會產生任何 API 費用**。上傳頁面有個「使用 AI 輔助解析」的勾選框，那是進階選項，遇到本地規則解析不準的證書才需要勾選，平常不用管它。

## 遇到問題怎麼辦

- **出現「Python was not found; run without arguments to install from the Microsoft Store...」**：
  這是 Windows 內建的「假 Python」捷徑，不是真的 Python。代表你的電腦其實還沒裝真正的 Python。
  請照「步驟 1」到 https://www.python.org/downloads/ 安裝，安裝畫面**務必勾選 "Add python.exe to PATH"**，
  裝完後重新雙擊 `START_HERE.bat`。如果裝完後還是出現同樣訊息，先重新開機再試一次。
  （若確定已經裝過還是不行，到 設定 → 應用程式 → 進階應用程式設定 → 應用程式執行別名，
  把 python.exe / python3.exe 兩個開關關掉）
- **視窗裡的文字都是英文**：這是刻意的——Windows命令視窗顯示中文常常會出現亂碼、甚至讓程式判斷錯誤，
  所以 `START_HERE.bat` 裡的訊息都改成英文，比較不會出錯。看不懂的英文錯誤訊息可以直接複製貼給我翻譯/判斷
- 出現一大串 `error: subprocess-exited-with-error` / `Unable to find Visual Studio` 之類的錯誤：
  通常是你的 Python 版本太新（例如剛發布沒多久的版本），有些套件還沒提供對應的現成安裝檔，
  導致電腦想「自己重新編譯」卻缺工具而失敗。把完整錯誤訊息貼給我，我可以調整 `requirements.txt`
  裡指定的套件版本來配合你的 Python 版本，不需要你自己裝 Visual Studio
- 瀏覽器沒自動打開：手動打開瀏覽器，網址列輸入 `http://127.0.0.1:8811`
- 其他問題：把黑色視窗裡出現的錯誤文字複製起來，回來這個對話貼給我，我幫你看
